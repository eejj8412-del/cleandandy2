# 샤시 구멍 복원 전문페이지

GitHub 저장소 최상단에 영문 이름의 `sash-hole-repair` 폴더 전체를 업로드합니다.

- 공개 주소: `https://allhousefix.co.kr/sash-hole-repair/`
- 메인 키워드: 샤시 구멍 복원
- 보조 키워드: 샷시 구멍 수리, 샤시 랜선 구멍, 이사 원상복구
- 실제 사례: 서울시 동대문구 청계한신휴플러스 아파트
- 사진 3개와 복원 전·후 영상 2개 포함

업로드 후 메인 홈페이지의 기존 `샷시 구멍 복원` 카드를 `/sash-hole-repair/`로 연결합니다.
