# 실크벽지 부분도배 전문페이지

GitHub 저장소 최상단에 영문 이름의 `wallpaper-installation` 폴더 전체를 업로드합니다.

- 공개 주소: `https://allhousefix.co.kr/wallpaper-installation/`
- 메인 키워드: 실크벽지 부분도배
- 보조 키워드: 뜯긴 벽지 수리, 강아지가 뜯은 벽지, 벽지 이사 원상복구
- 실제 사례: 충청북도 청주시 오송대원칸타빌 아파트
- 사진 3개와 시공 전·후 영상 2개 포함

메인 홈페이지에 새 `실크벽지 부분도배` 카드를 추가하고 `/wallpaper-installation/`로 연결합니다.

## 메인 홈페이지 카드 연결 코드

```html
<article style="position:relative; cursor:pointer;">
  <span class="service-icon">▧</span>
  <h3>실크벽지 부분도배</h3>
  <a
    href="/wallpaper-installation/"
    aria-label="실크벽지 부분도배 페이지 보기"
    style="position:absolute; inset:0; z-index:10;"
  ></a>
</article>
```
