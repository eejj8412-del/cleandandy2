# 붙박이장·신발장 복원 전문페이지

GitHub 저장소 최상단에 영문 이름의 `built-in-cabinet-repair` 폴더 전체를 업로드합니다.

- 공개 주소: `https://allhousefix.co.kr/built-in-cabinet-repair/`
- 메인 키워드: 붙박이장 복원, 신발장 복원
- 보조 키워드: 붙박이장 찍힘 복원, 신발장 찍힘 수리, 가구 필름 벗겨짐 부분수리
- 실제 사례: 경기도 남양주시 다산리버펠리체2단지
- 사진 3개와 수리 전·후 영상 2개 포함

업로드 후 메인 홈페이지의 기존 `붙박이장·신발장 복원` 카드를 `/built-in-cabinet-repair/`로 연결합니다.
